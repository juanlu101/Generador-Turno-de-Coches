Generador de Turno de Coches para docentes.

Se necesita un formulario de Google Forms, exportar las respuestas csv e importar el csv en el generador.

Tiene las siguientes características:
- Cada persona conduce 2 veces por semana
- Prioriza que vayan hasta 4 personas por coche (incluyendo al conductor).
- Permite descargar imagen para compartir el cuadrante generado.
- Se puede forzar que una determinada persona conduzca un día concreto si es posible.
- El generador no tiene memoria, pero permite descargar el estado del cuadrante en json y cargarlo posteriormente para recuperar el estado anterior.
